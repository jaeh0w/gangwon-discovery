# 강원 발견 · Next Hot Place

강원 지역의 여행 테마와 관광 데이터를 살펴볼 수 있는 웹페이지와 데이터 자료입니다.

**서비스:** https://devist.co.kr/dataton/

## 구성

- `index.html`: 서비스에 배포한 HTML 원본. 지도 라이브러리와 주요 데이터가 포함되어 있습니다.
- `data/`: 정리한 CSV 5개, Excel 파일 1개와 `원본CSV/`의 CSV 4개.

데이터에는 관광 수요, 관광지, 상가, 숙박업, 관광 자원, 여행 키워드, 시군 지표, 전통시장 자료가 포함되어 있습니다. 파일 내용은 제공받은 원본 그대로이며, 한글 파일명은 GitHub에서 읽기 쉽도록 유니코드 NFC 형식으로 통일했습니다.

## 실행

저장소를 내려받은 뒤 폴더에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000/ 에 접속합니다. 외부 글꼴, 지도 및 날씨 등 일부 기능은 인터넷 연결이 필요합니다.

## 자료 출처와 이용

웹페이지의 **자료·출처** 메뉴에서 출처 정보를 확인할 수 있습니다. 공공데이터, 관광지 사진, 지도와 외부 라이브러리에는 각 제공자의 이용 조건과 저작권이 적용됩니다. 이 저장소의 공개가 해당 자료 전체에 별도의 오픈소스 라이선스를 부여하는 것은 아닙니다.
